المخطط التأسيسي — منصة تجارة الجملة الإفريقية الذكية
الإصدار: 1.0 — 2026-10-18
الحالة: وثيقة تخطيطية، لا دليل متحقق على تنفيذ المنصة.
الهوية: سوق B2B متعدد الموردين، المغرب أولاً، وإفريقيا بالتوسع المرحلي.  
الرؤية والمبادئ
- استلهام أفضل التجارب من Alibaba وAliExpress وAmazon دون نسخ ملكيتهم الفكرية أو شيفرتهم.
- البساطة أمام المستخدم، الذكاء الاصطناعي خلف الوظائف، والمورد يراجع قبل النشر.
- شبكة مصانع ومستوردين وموزعين وتجار جملة ومشترين مهنيين.
- تجارة الجملة هي الأساس: MOQ، أسعار حسب الكمية، RFQ، ثقة الموردين.
- متعدد البلدان والعملات واللغات على مستوى التصميم، التشغيل يبدأ بالمغرب.
المستخدمون
- مشتري مهني: بحث، مقارنة، RFQ، متابعة العروض.
- مورد: متجر، منتجات، أسعار، صور، مخزون، الرد على RFQ.
- موظف مورد: صلاحيات محددة داخل منظمة.
- إدارة المنصة: مراجعة، توثيق، بلاغات، سجلات تدقيق.
رحلة المورد
إنشاء حساب ← ملف الشركة ← متجر ← صورة المنتج ← استخراج مسودة (اسم/فئة/وصف) ← مراجعة السعر وMOQ والخصائص ← اعتماد الصور والنشر.
شروط الصورة: حقوق واضحة، تحسين واقعي، لا نسخ عشوائي لصور الغير، ولا تخمين مواصفات أو أسعار أو مخزون. المورد يوافق صراحة على النشر.
الحقول الإلزامية: عنوان، فئة، صورة يملك حق استخدامها، سعر/اطلب سعراً، عملة، وحدة بيع، MOQ، موقع توريد، توافر، مورد، وصف كافٍ.
رحلة المشتري
صورة/نص ← نتائج داخلية مطابقة ثم مشابهة ← تصفية حسب موقع/كمية/سعر/مورد ← طلب عرض سعر. عند عدم التوفر: طلب توريد + بحث خارجي تجريبي عبر واجهات/مصادر تسمح بالاستخدام، مع روابط واضحة وعلامة «خارجي» وبدون ادعاء تحقق.
MVP — قدرات أساسية
1. حسابات وأدوار ومنظمات ومتاجر مع مراجعة أساسية.
2. كتالوج جملة: صور، MOQ، وحدات، أسعار طبقية، حالة توفر.
3. مسودة منتج بالذكاء الاصطناعي من صورة + مراجعة يدوية.
4. بحث نصي وفلاتر وبحث بالصورة داخل كتالوج المنصة.
5. RFQ وإشعارات وردود ومتابعة.
6. لوحة مشرف وتوثيق أولي وبلاغات وسجل إجراءات.
7. العربية والفرنسية وواجهة متجاوبة.
8. تجربة محدودة للبحث الخارجي عند غياب المنتج، فقط ضمن مصادر متاحة قانونياً.
لاحقاً: الدفع والضمان التجاري والشحن المدمج، ERP، تطبيق الجوال، بحث خارجي موسع، التوسع الجغرافي.
الذكاء الاصطناعي
- فهم الصورة والتصنيف.
- إنشاء مسودات العنوان والوصف والترجمات.
- بحث بصري وهجين مع تمييز المطابق عن المشابه.
- اكتشاف روابط موردين خارجيين عبر مصادر مسموح بها.
- تحسين إعداد RFQ وعرض المقارنات دون اختلاق البيانات.
تصور تقني (غير نهائي)
- Frontend: Next.js + TypeScript، واجهة هاتف أولاً.
- API: Modular Monolith بوحدات Accounts / Catalog / RFQ / Admin.
- Data: PostgreSQL + Object Storage + CDN.
- Search: نصي + تشابه بصري/متجهات على مراحل.
- Jobs: queue للمهام الثقيلة؛ AI provider adapter؛ monitoring وتدقيق.
- Entities: User, Organization, Membership, SupplierProfile, Store, Product, ProductVariant, PriceTier, InventorySnapshot, MediaAsset, QuoteRequest, QuoteOffer, MessageThread, ExternalDiscoveryResult, VerificationCase, ModerationCase, AuditEvent.
- security: tenant isolation، RBAC، file checks، rate limiting، backups، audit logs.
مراحل التنفيذ
0. مقابلات بحث سوق واعتماد نطاق MVP.
1. حسابات ومتاجر وكتالوج ومشرف.
2. مسودة AI وبحث بالصورة وRFQ.
3. تجربة مغربية بموردين ومشترين حقيقيين.
4. توسع إفريقي بلدًا ببلد بعد تدقيق تشريعي ولوجستي.
مهام الانطلاق
T01 اعتماد الأدوار والنطاق.
T02 مقابلات 10–15 مورداً و5–10 مشترين (هدف مقترح).
T03 خرائط الرحلات والواجهات.
T04 ERD والصلاحيات.
T05 مستودع وهيكل المشروع.
T06 الحسابات والمتاجر.
T07 الكتالوج والتسعير.
T08 مسودة من صورة مع مراجعة.
T09 بحث نصي/بصري واختبار مطابق/مشابه.
T10 RFQ والمشرف والتدقيق.
أسئلة قبل البناء
الفئات الأولى، المدينة التجريبية، مستوى التوثيق، حقوق الصور، مصادر البحث الخارجي، نموذج الإيراد، الامتثال لكل بلد.
اختبارات قبول التجربة: متجر ومنتج لمورد غير تقني، دقة تمييز النتائج، طلب سعر متكامل، مراجعة الصور، عزل حسابات الموردين، سجل الإشراف.
مقابلات السوق: أسئلة عملية عن تجهيز الكتالوج، اكتشاف المورد، الثقة، البحث بالصورة، والاستعداد للدفع.
الخطوة التالية: اعتماد نطاق MVP، ثم T01–T03 مع إشراك موردين ومشترين حقيقيين. لا تفترض هذه الوثيقة إنجاز أي مكون برمجي.
