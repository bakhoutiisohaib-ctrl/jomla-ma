# Gate 6C.3B.1B.4 — isolated native broker integration

**PASS_SCOPED_LAB; not a production acceptance.** Baseline 65fddcd8fd400817484814058b321c1be03798db. Integrated the exact existing Node worker contract and videoContainer service with the existing Linux isolation launcher through a one-shot root-provisioned Unix-domain supervisor. Node caller and client run as dedicated non-root UID/GID 61002; native tools run under UID/GID 61001 inside the prior chroot/seccomp/rlimit boundary. No network listener or application route. Operator-only synthetic lab.

The supervisor checks peer UID/GID using SO_PEERCRED, strict request fields and UUID, 4 KiB header, 20 MiB payload and input hash. Fixed command arguments and pipe-only FFmpeg input; no shell or user-defined paths. A bounded selector pumps each native process, refuses stderr and extra client bytes, observes client disconnect, enforces 12s per native step and 38s request deadline, and kills/reaps its process group in failure cleanup. Probe, full source decode, normalize, output probe and output decode run under the prior isolation launcher. Single silent video track, H.264/VP8/VP9 input, dimension/pixel and decoded duration limits, H.264 MP4 output at 24 fps, receipt validated by the existing Node contract. Decoded source progress is an additional limit, not a proof of arbitrary timestamp integrity. The supervisor locks the jail directory across its lifetime; concurrent use of that same jail is refused. References: https://ffmpeg.org/ffmpeg-protocols.html and https://docs.python.org/3/library/subprocess.html.

## Remaining boundary

The root supervisor is an offline proof of concept, not a privileged production service. A same-jail lock is not a global job scheduler across separate jails. No cgroup aggregate cap, supervisor SIGKILL/host-crash recovery, target Ubuntu service setup, pinned production runtime, durable queue, end-to-end upload authorization, storage or public playback verified. The cancellation test covers disconnection of a synthetic client during an actual dropped-UID native process, not every cancellation race or crash. Full source and output decode tested for two synthetic files only; conservative policy can reject legitimate clips. No claim of complete validation or general sandbox security. No new application dependencies, CSS, reference design, original checkout or original DB changes. Upload remains disabled. Next: a separately tested production-candidate worker deployment contract with aggregate limits and lifecycle/crash recovery, then private storage/ownership and product integration; do not deploy as part of Git synchronization.
