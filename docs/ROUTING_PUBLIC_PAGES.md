# الروابط العامة ومتطلبات الاستضافة — C2

روابط React الحالية مبنية على History API و`popstate`، مع `<a href>` حقيقية تدعم نسخ الرابط وفتح تبويب مستقل والنقر المعدل. لم تُضف اعتماديات أو يُعد بناء هيكل المشروع. يفترض التطبيق الاستضافة في جذر النطاق `/`، وهو افتراض بناء CRA الحالي.

| المسار | الوظيفة |
|---|---|
| `/` | السوق والبحث والمقارنة الحالية |
| `/stores` | دليل المتاجر العامة المؤهلة |
| `/products/:id` | تفاصيل منتج عام مؤهل بمعرف Mongo ثابت |
| `/stores/:id?q=...&page=...` | متجر عام، مع بحث وترقيم داخل المتجر محفوظين في URL |
| `/suppliers/:id` | صفحة المورد العامة الموجودة مسبقاً |
| `/login`, `/register` | المصادقة مع وجهة عودة داخلية معتمدة عند الحاجة |
| `/buyer`, `/supplier`, `/admin` | مساحات الحساب الحالية وبواباتها وصلاحياتها |

معرفات أسماء المنتجات والمتاجر لا تدخل الرابط. تغيير الاسم أوslug لا يحتاج ترحيلاً. الروابط غير المعروفة/المعرف غير الصحيح تعرض رسالة واضحة؛ المعرف الصحيح الذي لم يعد عاماً يعرض «غير متاح». لا يكشف رابط عام مسودة حتى لصاحب جلسة مالك أو مشرف. واجهات التحرير الخاصة تبقى في مساراتها المصادق عليها.

تُحفظ جلسة الدخول بالطريقة السابقة. العودة بعد المصادقة لا تقبل نطاقاً خارجياً أو مسار مصادقة دائرياً أو مساحة حساب لا تتبع الدور. النقر على RFQ كزائر يحفظ مرجع المنتج وقصد فتح النموذج في returnTo؛ بعد دخول المشتري يُفتح النموذج الحالي وتُزال علامة القصد من URL. إرسال الطلب يتطلب ضغط المستخدم زر الإرسال، ويخضع لـAPI الحالي.

مرشحات السوق القديمة وصورة البحث وداخل تبويبات مساحات الحساب تبقى حالة واجهة محلية كما كانت؛ لا ندعي حفظ ملف صورة البحث أو كل نموذج عند F5. صفحات المنتج والمتجر وموضع مساحة الحساب محفوظة بالمسار، وبحث المتجر وترقيمه محفوظان بالاستعلام.

## SPA fallback عند الاستضافة لاحقاً

التحديث وفتح تبويب جديد يرسلان طلب HTTP للمسار كاملاً. يجب على مضيف الواجهة تقديم `frontend/build/index.html` لطلبات صفحات التطبيق التي لا تطابق ملفاً حقيقياً. تجري React بعدها فحص المسار، وتطلب API الذي يتحقق من الأهلية العامة الحية.

الترتيب المطلوب:

1. توجيه `/api/*` و`/health/*` إلى الخادم مع الحفاظ على البادئة، ودون استبدال أخطائها بـHTML.
2. استمرار حجب `/uploads/*` وكل تقديم مباشر لمجلد الصور؛ قراءة الصور عبر `/api/media/*` وفحوصه فقط.
3. خدمة ملفات build الموجودة، وإرجاع404 للـstatic asset المفقود، حتى لا يصل index.html مكانJavaScript.
4. تقديم index.html لطلبات مستندات الواجهة فقط، مع الحفاظ على querystring. المضيف الحالي يحتاج جذراً `/`؛ الاستضافة تحت مجلد فرعي تحتاج قرار basename/public path منفصلاً.

تطبق [المعاينة الاصطناعية](../backend/scripts/phase-c2-preview.js) هذا الفصل. اختبرت HTTP لروابط المنتج والمتجر، وخطأ API، وملفstatic مفقود، و/uploads. لم نغير [قالب Caddy التاريخي](../ops/pilot/Caddyfile.example) أوVPN أو ننشره؛ يبقى حجب الميديا السابق فيه بوابة تشغيل يجب مراجعتها منفصلة، كما يحتاج تمييزstatic المفقود عنfallback المستندات. لا يعني نجاح المعاينة أن إعداد الاستضافة منشور أو معتمد.

قد يردfallback للروابط غير المعروفة بـHTTP200 ثم تعرض React صفحة خطأ؛ هذا soft404 على مستوى SEO. API نفسه يعيد404 فعلياً. إرجاع حالة مستند دقيقة من الخادم أوSSR/metadata قبلJavaScript عمل مستقل؛ لا نُدخل استثناء يعرض منتجاً خاصاً لتحقيقه.

## معاينات WhatsApp وSEO

توجد روابط href مستقرة وtitle وdescription وcanonical في DOM بعد جلب المنتج/المتجر العام. HTML الأولي يظل قالبCRA ببيانات عامة لـJomla.ma، ولا يحتوي اسم المنتج أوog:image خاصاً به. أثبت ذلك فحصHTTP دون تشغيلJavaScript، وقورن ببياناتDOM المتصفح.

النتيجة: مشاركة الرابط والانتقال إليه تعمل، لكن **معاينة WhatsApp باسم المنتج وصورته ليست معتمدة أو مضمونة** في هذه الجولة. لا يمكن لخادم خارجي الوصول إلى localhost، ولم نرسل رسالة WhatsApp أو ننشر موقعاً لاختبار معاينة حقيقية. بعض الزواحف لا تشغلJavaScript، ويمكنها الاكتفاء بالقالب العام؛ هذا استنتاج من فرقHTML/DOM ومن [إرشاداتGoogle لـJavaScript SEO](https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics). يحدد [Open Graph](https://ogp.me/) حقولtitle/type/image/url للمعاينة الغنية؛ لا تدعي البيانات العامة الجزئية في قالبنا تنفيذها لكل منتج.

يمكن دراسة توليدmetadata/HTML عام على الخادم بصورة محدودة لاحقاً، مع فحص الأهلية نفسه لكل طلب وحماية الأسرار والميديا؛ لا تستلزم هذه الملاحظة فرض هجرة تقنية شاملة. لم ننفذSSR أوprerender أوsitemap أوhreflang أوتطبيقاً جديداً. اللغة تفضيل واجهة محفوظ محلياً، وليست مسارات فهرسة لغوية مستقلة حالياً.
