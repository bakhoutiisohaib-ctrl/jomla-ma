# فحص الإعدادات قبل التشغيل

من جذر المستودع:

```powershell
node scripts/preflight.js
```

تقرأ الأداة `backend/.env` مع أولوية متغيرات البيئة الموجودة، وتعيد JSON بحقلين `status` و`findings`. لا تشغّل التطبيق ولا تستورد نماذجه، ولا تنشئ فهارس أو مجلدات أو ملفات أو مهام. لا تفتح اتصال MongoDB افتراضياً، ولا تتصل بـClaude أوBrave أوRedis. لا تفحص المنافذ ولا تنشر الموقع.

يشمل الفحص صيغة اتصال MongoDB ووجود اسم قاعدة صريح، والطول الأساسي وسلامة القيم التجريبية لـJWT، وCORS محدداً دون wildcard في الإنتاج، ومجلد `UPLOADS_DIR` المطلق الموجود وإمكان القراءة والكتابة بواسطة فحص الوصول فقط، ووضع العامل `embedded` أو`external`. عند غياب `UPLOADS_DIR` يفحص المجلد الافتراضي `backend/uploads`. لا يكتب ملف اختبار لإثبات الوصول ولا يتحقق من دوام القرص أو سعته أو النسخ الاحتياطي. إعداد العامل لا يثبت أن عملية عامل مستقلة تعمل فعلاً.

وجود إعداد Claude أوBrave يعني أن عناصر الإعداد موجودة فقط؛ لا يثبت أن المفتاح صالح أو أن الفوترة والنموذج متاحان أو أن نتائج الخدمة صحيحة أو أن الشروط اعتُمدت قانونياً. غياب الخدمات الاختيارية أو اختيار عامل خارجي غير مفحوص يظهر تحذيراً واضحاً.

لإضافة اتصال وطلب `ping` فقط إلى قاعدة البيانات، دون قراءة مجموعات التطبيق أو حساب أعدادها أو كتابة بيانات:

```powershell
node scripts/preflight.js --check-db
```

ميزانية اتصال وطلب ping الافتراضية خمس ثوان. فشل الوصول يظهر تحذيراً؛ لا تُعرض رسالة خطأ MongoDB الخام ولا URI ولا أسماء قواعد أو مستخدمين أو مسارات أو مفاتيح. نجاح ping يثبت الاستجابة في ذلك الوقت، ولا يثبت صحة الرحلات التجارية أو صلاحية الكتابة أو سلامة البيانات. لا يستخدم الفحص `Model.init()` أوامر إنشاء فهارس.

`status=blocked` يعني وجود خطأ إعداد يمنع الاعتماد، ويكون رمز الخروج `1`. `warnings` يعني وجود قدرات اختيارية غير معدة أو فحص وصول فاشل أو عامل خارجي لم يثبت تشغيله؛ رمز الخروج `0` ما دامت لا توجد أخطاء إعداد قاتلة. `ok` يعني مرور هذه الفحوص المحدودة فقط. راجع دائماً كل finding ولا تفسر رمز الخروج وحده على أنه تصريح بالإطلاق أو دليل اتصال قاعدة عند عدم طلبه.

لحفظ التقرير، وجّه stdout إلى ملف جديد في مكان مناسب:

```powershell
node scripts/preflight.js --check-db > reports/preflight-local.json
```

الأداة نفسها لا تحفظ تقريراً. حفظه في المثال فعل shell صريح. تجنب إضافة URI أو مفاتيح أو إعدادات كاملة إلى التقرير. اختبارات `backend/tests/preflight.test.js` تمرر بيئة مصطنعة مباشرة، ولا تقرأ ملف إعداد المستخدم ولا تفتح قاعدة حقيقية، وتتحقق من عدم ظهور القيم الخاصة ومن ping وحده ومن رفض الإعدادات الخطرة.
