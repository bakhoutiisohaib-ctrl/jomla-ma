Added videoWorkerLab.js, a nonprivileged caller-side protocol experiment with explicit trusted operator command configuration, no shell, fixed argument copy, reduced environment, no fallback and no application wiring. Input is structurally checked, copied before asynchronous work and sent over pipes with a bounded length-prefixed JSON header, random job ID, exact byte count and SHA-256. A single worker instance admits one job at a time with no queue. Output requires exit 0, closed stdio, no diagnostic bytes, exact receipt fields, matching job/input hashes, output bytes/hash, H.264 MP4 policy, 24 fps, frame/duration consistency, bounded dimensions and structural MP4 preflight. A receipt is not proof of actual decoding, sandbox identity or trusted provenance. The synthetic peer intentionally echoes non-decodable envelope fixtures; previous native decode and Linux isolation evidence remain separate.

Provisional limits: 20 MiB input/output payload, 4 KiB header, 128 KiB stderr, default 45s wall timeout and 2s termination grace. On failure/cancel the worker requests SIGKILL, stops accepting output and discards queued stdin. It retains its slot until process close; if close cannot be confirmed in grace period it quarantines the instance permanently, even after a late close. A malformed cancellation object is refused before admission. No raw process diagnostics returned to callers. Node child process close/kill semantics reference: https://nodejs.org/api/child_process.html.
